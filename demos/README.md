# Demos

Proof-of-concept materials for the two installations. Organized by the system each demo belongs to.

```
demos/
├── tarot-room/              Physical audio-spatial tarot installation
│   ├── voice/               TTS / voice synthesis tests
│   └── ambient/             Ambient sound experiments
├── embodied-agents/         Unity MARL temple agents (WIP)
└── supplementary/           Adjacent generative experiments
    ├── prayer-machines/      N-gram text trained on religious texts
    └── mandala-texture/      StyleGAN latent-walk video for sphere texture
```
